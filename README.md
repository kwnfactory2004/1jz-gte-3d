# 1JZ-GTE 3D
トヨタ 1JZ-GTE（後期型・VVT-i・シングルターボ）の中の動きを、ブラウザで回して見られる勉強用3Dモデル。

🔗 **公開URL**: https://kwnfactory2004.github.io/1jz-gte-3d/

## 機能
- 通常版（`view.html`）とカットモデル版（`cutaway.html`）
- クランク・ピストン・コンロッド・カム・バルブ・タイミングベルトが動く
- 再生／一時停止／3°ずつ進める／はやさ、クランク角度の表示
- 6気筒それぞれの行程（吸入・圧縮・燃焼・排気）を色で表示
- 外側を透かす、部品グループの表示・非表示、クリックで部品名

## 使い方
1. 公開URLを開いて、通常版かカットモデル版を選ぶ
2. ドラッグで回す・ホイールで寄る・右ドラッグで動かす

## 技術
HTML / JavaScript（three.js を CDN から読み込み）。3Dモデル（glTF・Draco圧縮）は各HTMLの中に埋め込み。モデルは Blender + Python で作成。

## 注意
主な寸法（内径86mm・行程71.5mm など）は公表値をもとにしているが、外まわりの位置や形は推定を含む。トヨタ公式のものではない、個人の勉強用の非公式モデル。
